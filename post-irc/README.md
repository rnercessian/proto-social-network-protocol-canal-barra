# Post-IRC Continuity

This directory contains records related to Canal Barra continuity after the core IRC/BRASnet period.

For this repository, the editorial cutoff is **20 May 2007**. Records whose represented event, project, organizational activity or web property belongs after this date should be classified under `post-irc/`.

This boundary is based on the represented historical object, not only on file creation date or later archival processing. In practice, a Wayback capture from 2011 of the Canal Barra portal should be treated as evidence of the 2011 post-IRC portal state, not as evidence of the 2002 IRC-era community. A post-2007 portal, directory, company, regional branch, cultural support record or revived web activity belongs to post-IRC continuity.

Post-IRC records are not used as direct evidence for the 1996-2007 Canal Barra IRC/BRASnet social phenomenon unless explicitly stated. They document later uses of the Canal Barra name, company structure, network effects, web presence, regional directory experiments, cultural/operational support and other afterlife developments.

## Classification Rule

Use `post-irc/` for records where the represented activity occurred after **20 May 2007**, including:

- regional directory or portal projects;
- company/consulting continuity;
- post-IRC web properties;
- revived Canal Barra initiatives;
- later uses of Canal Barra social capital;
- cultural, operational or institutional support records;
- founder-adjacent continuity only when the Canal Barra name, company, network or social capital is materially involved.

Do not use `post-irc/` for:

- IRC logs from the core period;
- archived profiles from the original community period;
- UFF 2004 material;
- IRContro records from the core period;
- governance/access records from the core period.
