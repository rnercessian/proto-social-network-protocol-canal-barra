# Media and Screenshot Archive

## Purpose

This folder is reserved for screenshot and media metadata related to Canal Barra.

Media files may provide evidence of:

- user lists;
- access lists;
- operator structures;
- event pages;
- VIP lists;
- historical website pages;
- flyers and public event materials.

## Privacy Rules

Do not publish:

- identifiable user photographs without permission;
- civil names linked to nicknames;
- emails;
- IP addresses;
- full hostmasks;
- private messages;
- sensitive personal information.

## Recommended Structure

```text
media/
├── screenshots/
│   ├── access-lists/
│   ├── user-lists/
│   ├── event-pages/
│   └── vip-lists/
├── flyers/
└── README.md
```

## Metadata Standard

Each screenshot should be indexed in `data/media-metadata/screenshots.json` with:

- screenshot id;
- filename;
- approximate date;
- source URL or origin;
- what it documents;
- what was redacted;
- privacy status;
- certainty level.

## Archival Principle

Screenshots should prove structure, scale and chronology without exposing unnecessary private information.
