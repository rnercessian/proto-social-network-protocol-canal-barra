# Contributing

## Purpose

This repository documents Canal Barra as a historical proto-social-network case.

Contributions should strengthen the evidence base, not inflate the narrative.

## Preferred Contribution Types

Useful contributions include:

- dated screenshots;
- Wayback URLs;
- event captions;
- nickname lists;
- operator/access-list records;
- corrections to dates, spellings and roles;
- source metadata;
- redacted documents;
- testimony clearly marked as memory, hypothesis or verified fact.

## Evidence Levels

Use one of these labels whenever possible:

```text
primary_document
archived_web_capture
photo_caption
founder_statement
participant_statement
third_party_reference
pending_verification
```

## Privacy Rules

Do not add:

- civil names unless already public, necessary and reviewed;
- private addresses;
- phone numbers;
- emails;
- CPF, IDs or private documents;
- identifiable user photos without permission or a clear archival basis;
- private messages;
- IP addresses or full hostmasks.

Prefer nickname-level metadata.

## Historical Nickname Rule

Preserve historical spelling.

Do not normalize nicknames too aggressively.

Examples:

```text
_pilar_ is not the same historical spelling as pilar.
+ and @ are IRC status prefixes, not part of the nickname.
```

## Claim Discipline

Separate:

```text
what the source proves
what the founder remembers
what is inferred
what still needs verification
```

Do not turn memory into proof.

Do not turn a source into a broader claim it cannot support.

## Branch / Review Recommendation

For substantial contributions, prefer a branch or pull request before editing central files.

Recommended workflow:

```text
1. Add source metadata.
2. Add or correct dataset rows.
3. Mark evidence level.
4. Explain what changed.
5. Avoid overwriting existing historical notes without discussion.
```

## Core Sentence

**This repository should remain auditable: every strong historical claim should point back to a source, a dataset row, a dated capture or a clearly labeled testimony.**
