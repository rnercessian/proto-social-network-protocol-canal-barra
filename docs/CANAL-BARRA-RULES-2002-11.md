# Canal Barra Rules — November 2002

## Source Context

Rules published on the Canal Barra website in November 2002.

This document is preserved as evidence of governance, operator structure, master-level accountability, event coordination and the link between the IRC channel and the official CanalBarra.com website.

## Historical Importance

These rules show that Canal Barra was not a random chat space. It had:

- public rules for visitors and users;
- rules for operators;
- rules for masters;
- IRContro coordination through the channel topic;
- official website integration;
- operator registration procedures;
- ChanServ governance documentation.

This supports the project thesis that Canal Barra functioned as an organic social network with persistent identity, hierarchy, governance, community memory and physical gatherings.

## Rules for Visitors and Users

### Not Allowed

- Fazer flood.
- Pegar Op sem estar cadastrado na lista de acesso.
- Pedir Op no canal aberto, ou ficar insistindo em PVT. Candidate-se a Operador.
- Fazer propaganda de outros canais em spam ou no canal aberto.
- Ofender ou ameaçar usuário(s) do canal.
- Fazer propaganda de sites em intervalos menores que 30 min.
- Rodar bots no canal.
- Enviar vírus, trojans ou arquivos maliciosos para usuários.
- Deixar um nickname "Away" enviando mensagem automática no canal.

### Allowed

- Fazer novas amizades, marcar encontros.
- Trocar fotos, mp3.
- Ficar conectado o dia todo.
- Roubar aliases.

## Rules for Operators

- Não retire do tópico informações do IRContro que vai haver ou estiver havendo no dia.
- Deixe a URL do site do canal (`WwW.CaNaLBaRrA.CoM`) no início do tópico.
- Não faça tópicos muito grandes que apaguem outras informações nele contidas.
- Mantenha seus dados do cadastro de Op atualizados, com telefone, UIN e foto.
- Se vierem pedir Op, encaminhe o usuário para a página de Operadores do canal #Barra: `http://www.canalbarra.com/operadores/`.
- Não deixe que seu script seja o último a reagir contra usuários maliciosos. Aplique as medidas de moderação do canal.

## Rules for Masters

- Mudanças no ChanServ devem ser documentadas no site do canal, apresentando justificativa.
- Procure obter a aprovação dos outros masters para dar ou tirar Op. Utilize o quadro de avisos.
- Troque a mensagem automática do canal se ela estiver indicando um evento que já passou.

## Data and Privacy Notes

The rules mention that operator registration could include phone, UIN and photo. These private fields are historically important because they prove administrative structure, but they must not be published in this repository.

This repository preserves the governance rule, not the private registration data.

## Analytical Summary

The November 2002 rules are direct evidence that Canal Barra had formalized governance and operational procedures:

| Dimension | Evidence in the rules |
|---|---|
| Community governance | Public rules for users, operators and masters |
| Status hierarchy | Users, operators, masters and access list |
| Event integration | IRContro information maintained in the topic |
| Website integration | Official CanalBarra.com URL required in topic |
| Accountability | ChanServ changes documented on the website |
| Recruitment | Operator candidacy routed through official page |
| Physical/social function | Rules explicitly allow making friends and arranging meetings |

## Core Sentence

The rules prove that Canal Barra was governed, documented and socially organized beyond ordinary chat behavior.
