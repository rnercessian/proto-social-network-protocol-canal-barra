# Canal Barra Lifecycle and the End of the IRC Core

## Purpose

This document defines how the repository should describe the end of Canal Barra's main social engine without confusing it with the later survival of the website or brand.

The key distinction is:

```text
#barra on BRASnet = live virtual meeting point / synchronous social core
CanalBarra.com = persistent web layer / archive / social display / later web property
Canal Barra = broader historical ecosystem
```

## Core Position

The end of the BRASnet network should be treated as the end of Canal Barra's original IRC core, not necessarily the absolute end of the Canal Barra name or website.

Safer wording:

```text
The shutdown of BRASnet on 20 May 2007 marked the end of the original IRC-based core of Canal Barra.
```

Avoid:

```text
Canal Barra ended completely in 2007.
```

Because CanalBarra.com reportedly continued online until around 2012, although with a different function and identity.

## Lifecycle Phases

### 1. Informal IRC use before registration — 1996 to 28 November 1997

Founder statement: #barra was already being used in 1996, before formal registration.

This phase should be described as:

```text
informal channel use / pre-registration phase
```

Evidence status:

```text
founder_statement
needs_archival_or_log_confirmation
```

### 2. Registered BRASnet channel — 28 November 1997

Founder statement: #barra was formally registered on BRASnet on 28 November 1997.

This date should be treated as the formal registration milestone, not necessarily the first day of social use.

Evidence status:

```text
founder_statement
needs_chanserv_or_archival_confirmation
```

### 3. Hybrid IRC + website social system — late 1990s to early 2000s

During the main phase, the IRC channel functioned as the live social meeting point, while CanalBarra.com functioned as the persistent web layer.

The loop was:

```text
IRC presence
→ topic / ENTRYMSG / user promotion
→ CanalBarra.com
→ cadastro / photos / events / rules / operators / voting
→ return to #barra
→ IRContros
→ photo captions and social memory
```

### 4. Decline of original IRC core — 2004 to 2007

The original IRC-centered model weakened as users migrated to newer platforms and messaging systems, especially MSN and Orkut.

This should be treated as:

```text
transition from IRC-centered community to platform-era social media fragmentation
```

### 5. End of BRASnet / end of original IRC core — 20 May 2007

Founder statement / external-source-needed note: BRASnet was reportedly shut down on 20 May 2007 after successive attacks and user migration to platforms such as MSN and Orkut.

This date should mark:

```text
end_of_original_irc_core
```

not:

```text
end_of_all_canal_barra_web_presence
```

### 6. Post-IRC website survival and identity shift — 2007 to 2012

Founder statement: CanalBarra.com continued existing until around 2012, but changed character.

Instead of operating as the web layer of the IRC community, it became closer to:

```text
blog / directory / local commerce and services guide for Barra da Tijuca
```

This phase should be treated as a legacy web-property phase, not the main social-network phase.

## Timeline Anchor Logic

Recommended timeline labels:

```text
1996: informal #barra use begins
1997-11-28: formal BRASnet registration of #barra
1999-2002: high-intensity hybrid IRC + website + IRContros phase
2004-2007: decline of IRC-centered core / migration pressure
2007-05-20: BRASnet shutdown / end of original IRC core
2007-2012: CanalBarra.com legacy website phase
2012: reported end of old legacy web phase
```

## Why This Matters

The main historical object is not only the website and not only the IRC channel.

It is the ecosystem:

```text
BRASnet channel
+ persistent website
+ nicknames
+ access hierarchy
+ rules
+ cadastros
+ IRContros
+ photo captions
+ local social circulation
```

The BRASnet shutdown ended the live infrastructure that made the original social engine work.

The website's later existence does not erase the 2007 break. It proves that the brand and domain survived after the original social form had already changed.

## Core Sentence

**20 May 2007 should be treated as the end of Canal Barra's original IRC-based social core, while the website's survival until around 2012 belongs to a separate legacy web-property phase.**
