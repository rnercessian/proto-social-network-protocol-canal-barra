# NOVICA Founding Webmaster and First Front-End Note

## Purpose

This document records a later-but-relevant web-history reference involving Raphael Nercessian / BarMan and NOVICA.

This is not direct evidence that Canal Barra was a social network.

It is relevant as founder web trajectory context: the same person who built and operated early Canal Barra web infrastructure was later publicly remembered as NOVICA's founding webmaster.

## Forbes Reference

Founder-provided Forbes article:

```text
https://www.forbes.com/sites/johngreathouse/2020/11/25/black-friday-gifts-with-meaning-this-entrepreneur-has-generated-over-100m-for-indigenous-artisans/
```

In the article, NOVICA cofounder Roberto Milk refers to Raphael Nercessian as a **founding webmaster** of NOVICA.

The same article describes NOVICA as having launched in a basement in Santa Monica.

## Founder Correction / Context

Founder statement: the Forbes reference should not be confused with the later six-month period Raphael spent between 1999 and 2000.

Founder statement: the founding webmaster/front-end episode occurred earlier, when the first NOVICA front-end was built in approximately three weeks in the basement of Roberto Milk's apartment.

This correction should be treated as founder-provided chronology context and should be verified, if possible, with archive captures, correspondence, source files, dated screenshots or additional testimony.
