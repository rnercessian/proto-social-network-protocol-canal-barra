# Índice cronológico de IRContros documentados — Canal Barra

> **Critério:** inclui encontros presenciais associados ao IRC e eventos culturais promovidos ou ligados ao Canal Barra, com classes distintas para não inferir presença de utilizadores a partir de um nome de banda. Cada acontecimento tem estatuto documental próprio. **Não é uma lista exaustiva** dos eventos de 1997–2007.
>
> **Datas históricas ≠ capturas Wayback:** data de fotografia, publicação, recolha de legenda ou captura não deve substituir a data do encontro. Eventos sem dia confirmado são agrupados por período.

"Peso" significa tratamento documental igual, **não** igual público ou estatuto de IRContro coletivo comprovado.

**Privacidade:** o índice não replica nomes familiares de espectadores, contactos, email, pagamentos, dados bancários ou observações confidenciais. Não deduzir a composição dos presentes.
