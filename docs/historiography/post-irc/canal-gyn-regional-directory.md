# Post-IRC Continuity: Canal Gyn Regional Directory

This record belongs to post-IRC Canal Barra continuity and is not used as direct evidence for the 1996–2007 Canal Barra IRC/BRASnet social phenomenon. Canal Gyn was a later regional partner site associated with Canal Barra, active approximately from 2010 to 2012, using "GYN" as a locally recognizable reference to Goiânia and operating as a digital directory/guide for commerce, leisure and services in the city.

The relevant context is that Canal Barra itself, by 2011, was no longer operating primarily as an IRC community interface; preserved Wayback evidence shows it functioning as a local web portal combining directory categories, blog/news posts, video blocks and advertising space. The directory section was reportedly implemented in Perl; this technical attribution should be treated as curator-provided implementation memory pending direct source or code confirmation. The evidence value is therefore limited and specific: Canal Gyn indicates that, after the original IRC period, the Canal Barra structure or brand attempted geographic replication of its post-IRC directory/blog model outside Rio de Janeiro. The site was reportedly maintained by Lidia; this maintainer attribution should be treated as curator-provided context pending direct confirmation.
