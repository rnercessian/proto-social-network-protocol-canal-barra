# Canal Barra Web Stack — From XOOM to ColdFusion and Microsoft Access

## Source Context

Founder statement: Canal Barra already had a website from 1997, hosted on the old XOOM platform at:

```text
members.xoom.com/barra
```

That early website predates the later database-backed version and included user photos, IRContro photos and classified-style announcements.

The early XOOM website was reportedly mentioned by a magazine from Grupo O Globo. This reference should be treated as evidence pending external recovery until the magazine citation, scan or bibliographic record is added to the repository.

From around 2000 onward, the Canal Barra website was rebuilt as a dynamic web application using ColdFusion with a Microsoft Access database.

The technical work is linked to the experience of the cousins BarMan and Lucas_Rio during their stay in Los Angeles:

- BarMan: approximately 6 months in Los Angeles;
- Lucas_Rio: approximately 1 year in Los Angeles.

The technology and approach were imported back into the Canal Barra context and applied to the community website.

## Technical Chronology

| Period | Web layer | Historical meaning |
|---|---|---|
| 1997 onward | Early Canal Barra website hosted on XOOM at `members.xoom.com/barra` | Public web presence before the dynamic database-backed phase |
| 1997-era content | User photos, IRContro photos and announcements | Evidence that the website already worked as a social extension of the IRC community |
| Reported external reference | Mention by a Grupo O Globo magazine | Evidence pending recovery; important for press recognition of the site |
| Around 2000 onward | ColdFusion + Microsoft Access | Dynamic cadastro, operators pages, rules, events and structured community data |

## Why This Matters

This is historically important because it shows that Canal Barra evolved beyond an IRC channel and had a web presence before the platform-social-media era.

The 1997 XOOM site shows early public web identity and social memory through photos, IRContros and announcements.

The 2000 ColdFusion + Microsoft Access phase shows a later and more structured web-backed community system.

By 2000, the Canal Barra ecosystem had at least two integrated layers:

1. the IRC/BRASnet channel layer;
2. the CanalBarra.com dynamic website layer.

The website supported structured public records such as:

- cadastro/user pages;
- operators pages;
- rules pages;
- event-related information;
- governance references;
- updateable community data.

## Technical Significance

A ColdFusion + Microsoft Access stack was unusual and relatively advanced for a small Brazilian community website of that period.

The relevant point is not only the technology itself. The relevant point is what the technology enabled:

- dynamic pages;
- database-backed community records;
- operator listings;
- public cadastro visibility;
- profile activation/deactivation behavior;
- structured governance pages;
- integration between IRC identity and website identity.

## The Announcement Layer and Cultural Production

The early XOOM website included announcements. According to the founder, the Banda do Canal Barra was assembled through one of these announcements.

Mad appears in the 1999 access-list material and later became part of this cultural layer of the Canal Barra story.

The band was later renamed **Malucos da Ponte** in 2000.

This matters because it shows that Canal Barra produced more than conversation. It generated cultural projects, recruitment, music and offline collaboration through the web/community layer.

## Link to Multi-Layer Identity

This technical chronology helps explain why Canal Barra cannot be reduced to a simple IRC room.

The community had multiple identity layers:

| Layer | Technical base | Historical function |
|---|---|---|
| IRC channel | BRASnet / IRC / ChanServ | Real-time presence, hierarchy, access levels and social interaction |
| Early website | XOOM hosting at `members.xoom.com/barra` | Public web presence, user photos, IRContro photos, announcements and cultural recruitment |
| Dynamic website | ColdFusion + Microsoft Access | Cadastro, operators pages, rules, event information and public community records |
| Physical events | IRContros and parties | Offline validation of online reputation and belonging |
| Cultural production | Banda do Canal Barra / Malucos da Ponte | Music and collaboration generated from the Canal Barra ecosystem |

## Link to the Operators Page

The 2002 public operators page is direct evidence of the dynamic web layer.

It shows that operator status was not only an IRC status. It was also represented on the official website.

This matters because a person could deactivate or disappear from the common cadastro list while still appearing in the public operators page.

That separation supports the idea that Canal Barra had layered identity and layered status.
