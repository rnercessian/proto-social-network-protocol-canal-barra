# Methodology and Product Vision

## Working Name

**Chronos Protocol** is the possible future product layer derived from the Canal Barra case.

The repository itself remains focused on Canal Barra. Chronos Protocol is the broader methodology suggested by this case.

## Product Vision

A reusable infrastructure for preserving, structuring and visualizing historical digital communities.

The system should help transform scattered digital traces into:

- timelines;
- nickname/entity indexes;
- event records;
- community graphs;
- source maps;
- JSON-LD knowledge graphs;
- RAG-ready documentation;
- public archive pages;
- privacy-aware datasets.

## Possible Modules

### 1. Legacy Community Parser

Tools to parse old exports, HTML pages, text files, forum dumps, IRC-related records and event lists.

### 2. Privacy Filter

Tools to detect and remove sensitive data such as emails, IP addresses, full hostmasks, phone numbers and private-message indicators.

### 3. Social Memory Graph

A graph model that maps pseudonymous identities, events, roles, sources and documented relationships without exposing civil identity.

### 4. Archive Site Generator

A static-site layer that turns structured datasets into readable public pages for researchers, journalists, community members and search engines.

### 5. RAG Dataset Builder

A controlled exporter that creates JSONL records for AI retrieval systems, separating historical evidence from interpretation.

## Canal Barra as MVP

Canal Barra is the first test because it combines:

- historical depth;
- scale of nicknames;
- offline event records;
- social hierarchy;
- documentary sources;
- cultural relevance;
- a clear historiographical thesis.

## Product Boundary

The product should never be framed as selling private user data.

The value is in preservation, structuring, research, visualization and responsible knowledge infrastructure.
